# 📋 Registro de Negocios B2B Solution

Una aplicación desarrollada en **Python** para registrar y administrar información de clientes y negocios de forma sencilla.

El objetivo es ofrecer una herramienta ligera que permita almacenar datos comerciales de manera local, sin depender de servicios externos o una conexión a Internet.

## ✨ Características

- Registro de clientes con códigos personalizados.
- Almacenamiento de números telefónicos.
- Registro de correos electrónicos.
- Gestión de información de empresas o negocios.
- Consulta rápida de registros.
- Base de datos local.
- Interfaz simple y fácil de utilizar.

## 🎯 Objetivo del proyecto

Este proyecto nace como una alternativa sencilla para gestionar contactos comerciales y clientes sin la complejidad de un CRM.

Se publica como **software de código abierto** para que cualquier persona pueda estudiarlo, adaptarlo a sus necesidades y contribuir con mejoras.

## 🚀 Requisitos

- Python 3.10 o superior

## 📦 Instalación

```bash
git clone https://github.com/LuVaAcAn/Registro-Negocios-B2B-Solution.git

cd Registro-Negocios-B2B-Solution

python app.py
```

## 📁 Archivos del proyecto

```
Registro-Negocios-B2B-Solution/
│
├── app.py            # Aplicación principal
├── build_exe.bat     # Script para generar el ejecutable
└── README.md
```

## 🔨 Compilar ejecutable

Si tienes instalado PyInstaller, puedes generar el ejecutable ejecutando:

```bat
build_exe.bat
```

Y si no lo tienes, ejecútalo de igual manera. Build_exe instalará todas las dependencias por ti.
